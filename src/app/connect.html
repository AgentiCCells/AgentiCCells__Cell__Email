Outreach outbox

The PrompTugal outreach vault: drafts written by agents, approved and sent by you. Its key arrives sealed to this page (above) and is kept sealed in this browser. Opening it needs the SG/Send access token (in step 2).

    What this page does, and does not

    • It sends you to Google's own consent screen. Google returns a token to this page in the address bar's fragment, which browsers never send to a server; the page removes it at once.
    • The Google token (with its expiry, about an hour) and the SG/Send access token are kept in this browser only sealed to the page's key, so a reload reconnects without asking again. Disconnect revokes the Google token and deletes it.
    • The page keeps one key pair in this browser, with private halves that cannot be read or exported, and vault keys sealed to it, so only this browser can open them. Clearing the site's data deletes them.
    • It reads your profile, your labels and, when you sync, each message's headers (from, to, subject, date, thread) and labels. No message body is read: the grant does not allow it. Nothing is ever written to Gmail.
    • Sync writes the twin into your vault through sgit's own vault library, served from this site: one file per message, a cleaned copy for agents, threads, labels, a correspondents index and a change feed. Everything is encrypted in this browser before it leaves.
    • The page can connect only to Google and to the vault service (dev.send.sgraph.ai), which stores ciphertext it cannot read.
    • Disconnect revokes the Google token at Google and deletes the kept copy; it expires within an hour regardless.
    • Run sync again later: it adds only the messages the vault does not have yet.
